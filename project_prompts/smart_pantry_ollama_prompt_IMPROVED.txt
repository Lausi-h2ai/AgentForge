# Smart Pantry & Recipe App - COMPLETE SPECIFICATION
# Ollama/Local LLM Optimized - Production-Ready

## Project Overview
Build a single-user MVP app for pantry management with receipt OCR parsing and AI recipe generation using **local Ollama models** (no OpenAI API required). Use Python/FastAPI backend, React frontend, PostgreSQL database.

**Key Design Decisions:**
- Use Ollama for all LLM tasks (recipe generation, receipt parsing)
- Start with simple regex parsing, enhance with LLM later
- Mock OCR initially, add real OCR as enhancement
- Focus on working end-to-end flow before optimization

## 🎯 EXACT User Experience Definitions

### Feature 1: Pantry Management

**User Flow - View Pantry:**
1. User lands on Pantry page (/pantry)
2. System fetches pantry items via GET /api/pantry
3. Display items in responsive grid (3 cols desktop, 2 tablet, 1 mobile)
4. Each card shows:
   - Ingredient name (bold, 18px)
   - Quantity + unit (gray, 14px)
   - Category badge (colored pill based on category)
   - Edit button (blue pencil icon, top-right)
   - Delete button (red trash icon, top-right)
5. If pantry empty: Show empty state with "Add your first item" button
6. Loading: Show skeleton cards (3 pulsing gray rectangles)
7. Error: Show red banner at top with "Failed to load pantry. Retry?"

**User Flow - Add Item:**
1. User clicks "+" FAB (floating action button, bottom-right, blue, 56px)
2. Modal slides up from bottom (300ms ease-out)
3. Modal shows form with fields:
   - Ingredient name (autocomplete enabled, shows suggestions after 2 chars)
   - Quantity (number input, step 0.1, min 0.01)
   - Unit (dropdown: units, grams, kg, liters, ml)
4. As user types ingredient name:
   - After 2 characters, call GET /api/ingredients/search?q={query}
   - Show dropdown with top 5 matches
   - Each suggestion shows name + category badge
   - Click suggestion to autofill
5. Validation (real-time, on blur):
   - Ingredient name: required, show red border + "Required" below
   - Quantity: must be > 0, show red border + "Must be positive"
6. Click "Add Item" button:
   - Disable button, show spinner inside button
   - Call POST /api/pantry with data
   - On success (201):
     * Close modal (slide down, 300ms)
     * Refresh pantry grid
     * Show green toast (top-right): "Item added successfully!"
     * Toast auto-dismisses after 3 seconds
   - On error (400 validation):
     * Keep modal open
     * Highlight invalid fields with red borders
     * Show error messages below fields
     * Show red toast: "Please fix errors"
   - On error (500 server):
     * Keep modal open
     * Show red toast: "Server error. Please try again."
7. Click "Cancel" or backdrop: Close modal without saving

**User Flow - Edit Item:**
1. User clicks pencil icon on item card
2. Modal opens with pre-filled values
3. Same validation as Add
4. On save: Call PATCH /api/pantry/{id}
5. Success: Update card in place (no full refresh), show "Item updated!" toast
6. Error: Same handling as Add

**User Flow - Delete Item:**
1. User clicks trash icon
2. Show confirmation dialog (centered overlay):
   - Title: "Delete [item name]?"
   - Text: "This action cannot be undone."
   - Two buttons: "Cancel" (gray) | "Delete" (red)
3. Click Delete:
   - Call DELETE /api/pantry/{id}
   - On success (200):
     * Fade out card (500ms)
     * Remove from grid
     * Show "Item deleted" toast
   - On error: Show error toast, keep card

### Feature 2: Recipe Generation

**User Flow - Generate Recipe:**
1. User navigates to Planner page (/planner)
2. Page shows:
   - Header: "Generate Recipe from Your Pantry"
   - Preference form (optional filters):
     * Cuisine dropdown (any, Italian, Chinese, Mexican, etc.)
     * Max time slider (15-120 min, default 60)
     * Difficulty radio (easy/medium/hard)
     * "Avoid ingredients" multi-select chips
   - "Generate Recipe" button (large, primary blue, center)
   - Previous recipes section (scrollable cards)
3. Click "Generate Recipe":
   - Disable button, change text to "Generating..." with spinner
   - Call POST /api/recipes/generate with preferences
   - Show loading state: Animated cooking pot icon with "Creating your recipe..."
   - Request typically takes 5-15 seconds
4. On success (201):
   - Hide loading state
   - Display recipe card (full width):
     * Title (24px, bold)
     * Meta info row: cuisine badge, time icon + minutes, difficulty
     * Ingredients section (collapsible, default open):
       - Bullet list with checkboxes (non-functional, visual only)
       - Each ingredient on own line
     * Instructions section (collapsible, default open):
       - Numbered list
       - Each step on own line
     * Action buttons row:
       - "Cook This" (primary button) → saves to history
       - "Regenerate" (secondary) → generates new recipe
       - "Save" (outline) → bookmarks recipe
5. On error:
   - Hide loading
   - Show error message: "Failed to generate recipe. [reason]"
   - Show "Try Again" button

**User Flow - Record Cooked Meal:**
1. User clicks "Cook This" on recipe card
2. Show modal: "Mark as Cooked?"
   - Date picker (default: today)
   - Rating stars (1-5, optional)
   - Notes textarea (optional)
   - "Save" | "Cancel"
3. Click Save:
   - Call POST /api/meals/history
   - Success: Show "Meal recorded!" toast, return to planner
   - Error: Show error toast

### Feature 3: Receipt Upload

**User Flow - Upload Receipt:**
1. User navigates to Receipts page (/receipts)
2. Page shows:
   - Upload zone (dashed border, centered):
     * "Drag & drop receipt or click to browse"
     * Accepted: images (jpg, png), text files
   - Previously uploaded receipts list below
3. User drops file or clicks to browse:
   - Show file name + size
   - Show "Upload" button (enabled)
4. Click "Upload":
   - Disable button, show progress bar (0-100%)
   - Call POST /api/receipts/upload (multipart/form-data)
   - On success (200):
     * Hide upload UI
     * Show receipt card with:
       - Filename
       - Upload date
       - "Parse Receipt" button (primary)
       - "View Raw" button (secondary)
5. Click "Parse Receipt":
   - Show parsing options dialog:
     * Radio: "Quick Parse (regex)" | "AI Parse (Ollama)"
     * Checkbox: "Add to pantry automatically"
     * "Parse" | "Cancel"
6. Click Parse:
   - Show loading: "Parsing receipt..."
   - Call POST /api/receipts/{id}/parse?use_llm=true/false
   - On success:
     * Display parsed items in table:
       - Columns: Item | Quantity | Unit | Confidence
       - Each row has checkbox (checked by default)
       - Edit icons to adjust quantity/unit
     * Show "Add Selected to Pantry" button
7. Click "Add Selected to Pantry":
   - Call POST /api/receipts/{id}/apply-to-pantry
   - Success: Show "{N} items added to pantry" toast
   - Navigate to pantry page to show results

## 🔌 COMPLETE API Specifications

### Pantry Endpoints

**1. GET /api/pantry**

Query Parameters:
- `user_id` (optional, default=1): User ID

Response (200 OK):
```json
{
  "items": [
    {
      "id": 1,
      "ingredient_name": "Milk 3.5%",
      "quantity": 2.0,
      "unit": "liters",
      "category": "Dairy",
      "updated_at": "2026-01-28T10:30:00Z"
    }
  ],
  "total": 15
}
```

Error (500 Internal Server Error):
```json
{
  "error": "DatabaseError",
  "message": "Failed to fetch pantry items",
  "details": "Connection timeout"
}
```

**2. POST /api/pantry**

Request Headers:
- Content-Type: application/json

Request Body:
```json
{
  "ingredient_name": "string (required, 1-200 chars)",
  "quantity": "number (required, > 0)",
  "unit": "string (required, enum: units|grams|kg|liters|ml)"
}
```

Response (201 Created):
```json
{
  "message": "Item added",
  "id": 42,
  "ingredient": {
    "id": 15,
    "name": "Milk 3.5%",
    "normalized_name": "milk",
    "category": "Dairy"
  }
}
```

Response (200 OK) - when item already exists:
```json
{
  "message": "Quantity updated",
  "id": 42,
  "previous_quantity": 2.0,
  "new_quantity": 4.0
}
```

Error (400 Bad Request):
```json
{
  "error": "ValidationError",
  "message": "Invalid input",
  "fields": {
    "ingredient_name": "Field is required",
    "quantity": "Must be positive number"
  }
}
```

Error (422 Unprocessable Entity):
```json
{
  "error": "ValidationError",
  "message": "Invalid unit",
  "fields": {
    "unit": "Must be one of: units, grams, kg, liters, ml"
  }
}
```

**3. PATCH /api/pantry/{item_id}**

Request Body:
```json
{
  "quantity": "number (required, > 0)",

}
```

Response (200 OK):

```json
  "message": "Item updated",
```

## 🗄️ COMPLETE Database Schema

```sql
-- Enable UUID extension
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- Users table (MVP: single user, but schema supports multi-user)
CREATE TABLE users (
    id INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    username VARCHAR(100) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Index for username lookups
CREATE INDEX idx_users_username ON users(username);

-- Ingredient catalog with normalization
CREATE TABLE ingredients (
    id INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    name VARCHAR(200) NOT NULL,
    normalized_name VARCHAR(200) NOT NULL,
    category VARCHAR(50) NOT NULL DEFAULT 'Other',
    default_unit VARCHAR(20) NOT NULL DEFAULT 'unit',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),

    -- Constraints
    CONSTRAINT unique_normalized_name UNIQUE(normalized_name),
    CONSTRAINT valid_category CHECK (
        category IN ('Dairy', 'Meat', 'Produce', 'Bakery', 'Pantry', 'Spices', 'Other')
    )
);

-- Indexes for ingredient search
CREATE INDEX idx_ingredients_name ON ingredients(name);
CREATE INDEX idx_ingredients_normalized ON ingredients(normalized_name);
CREATE INDEX idx_ingredients_category ON ingredients(category);
-- Full-text search index
CREATE INDEX idx_ingredients_search ON ingredients 
    USING gin(to_tsvector('english', name || ' ' || normalized_name));

-- User's pantry inventory
CREATE TABLE pantry_items (
    id INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    ingredient_id INTEGER NOT NULL REFERENCES ingredients(id) ON DELETE RESTRICT,
    quantity DECIMAL(10,2) NOT NULL CHECK (quantity > 0),
    unit VARCHAR(20) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),

    -- Constraints
    CONSTRAINT unique_user_ingredient UNIQUE(user_id, ingredient_id),
    CONSTRAINT positive_quantity CHECK (quantity > 0)
);

-- Indexes for pantry queries
CREATE INDEX idx_pantry_user ON pantry_items(user_id);
CREATE INDEX idx_pantry_ingredient ON pantry_items(ingredient_id);
CREATE INDEX idx_pantry_updated ON pantry_items(updated_at DESC);

-- Recipes (manual or AI-generated)
CREATE TABLE recipes (
    id INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    title VARCHAR(200) NOT NULL,
    ingredients_json TEXT NOT NULL DEFAULT '[]',
    instructions_json TEXT NOT NULL DEFAULT '[]',
    source VARCHAR(20) NOT NULL DEFAULT 'generated',
    cuisine VARCHAR(50),
    time_minutes INTEGER,
    difficulty VARCHAR(20),
    tags_json TEXT NOT NULL DEFAULT '[]',
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    created_by_user_id INTEGER REFERENCES users(id),

    -- Constraints
    CONSTRAINT valid_source CHECK (source IN ('generated', 'manual', 'imported')),
    CONSTRAINT valid_difficulty CHECK (difficulty IS NULL OR difficulty IN ('easy', 'medium', 'hard')),
    CONSTRAINT positive_time CHECK (time_minutes IS NULL OR time_minutes > 0)
);

-- Indexes for recipe search
CREATE INDEX idx_recipes_cuisine ON recipes(cuisine);
CREATE INDEX idx_recipes_difficulty ON recipes(difficulty);
CREATE INDEX idx_recipes_time ON recipes(time_minutes);
CREATE INDEX idx_recipes_created ON recipes(created_at DESC);
-- Full-text search on title
CREATE INDEX idx_recipes_title_search ON recipes USING gin(to_tsvector('english', title));

-- Meal history (tracking cooked meals)
CREATE TABLE meal_history (
    id INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    recipe_id INTEGER NOT NULL REFERENCES recipes(id) ON DELETE CASCADE,
    cooked_date TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    rating INTEGER CHECK (rating IS NULL OR (rating >= 1 AND rating <= 5)),
    notes TEXT,

    -- Constraints
    CONSTRAINT valid_rating CHECK (rating IS NULL OR (rating BETWEEN 1 AND 5))
);

-- Indexes for history queries
CREATE INDEX idx_history_user ON meal_history(user_id);
CREATE INDEX idx_history_recipe ON meal_history(recipe_id);
CREATE INDEX idx_history_date ON meal_history(cooked_date DESC);
CREATE INDEX idx_history_user_date ON meal_history(user_id, cooked_date DESC);

-- Receipt records
CREATE TABLE receipts (
    id INTEGER PRIMARY KEY GENERATED ALWAYS AS IDENTITY,
    user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    file_path VARCHAR(500) NOT NULL,
    filename VARCHAR(255) NOT NULL,
    size_bytes INTEGER,
    raw_text TEXT DEFAULT '',
    parsed_data_json TEXT,
    processed BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    processed_at TIMESTAMP WITH TIME ZONE
);

-- Indexes for receipt queries
CREATE INDEX idx_receipts_user ON receipts(user_id);
CREATE INDEX idx_receipts_processed ON receipts(processed);
CREATE INDEX idx_receipts_created ON receipts(created_at DESC);

-- Trigger function to update updated_at timestamp
CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- Apply trigger to pantry_items
CREATE TRIGGER pantry_items_updated_at
    BEFORE UPDATE ON pantry_items
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();

-- Apply trigger to users
CREATE TRIGGER users_updated_at
    BEFORE UPDATE ON users
    FOR EACH ROW
    EXECUTE FUNCTION update_updated_at_column();

-- Seed default user

    ('Ground Beef', 'ground beef', 'Meat', 'kilograms'),
```

### Example 1: AddPantryItemModal.jsx (Frontend)

```javascript
import React, { useState, useEffect } from 'react';
import { toast } from 'react-toastify';
import api from '../api/client';

function AddPantryItemModal({ isOpen, onClose, onSuccess }) {
  const [formData, setFormData] = useState({
    ingredient_name: '',
    quantity: '',
    unit: 'units'
  });
  const [errors, setErrors] = useState({});
  const [loading, setLoading] = useState(false);
  const [suggestions, setSuggestions] = useState([]);
  const [showSuggestions, setShowSuggestions] = useState(false);
  const [searchLoading, setSearchLoading] = useState(false);

  // Reset form when modal opens
  useEffect(() => {
    if (isOpen) {
      setFormData({ ingredient_name: '', quantity: '', unit: 'units' });
      setErrors({});
      setSuggestions([]);
    }
  }, [isOpen]);

  // Autocomplete search
  useEffect(() => {
    const searchIngredients = async () => {
      if (formData.ingredient_name.length < 2) {
        setSuggestions([]);
        return;
      }

      setSearchLoading(true);
      try {
        const response = await api.get(`/api/ingredients/search?q=${formData.ingredient_name}`);
        setSuggestions(response.data.results || []);
        setShowSuggestions(true);
      } catch (error) {
        console.error('Search failed:', error);
      } finally {
        setSearchLoading(false);
      }
    };

    const debounceTimer = setTimeout(searchIngredients, 300);
    return () => clearTimeout(debounceTimer);
  }, [formData.ingredient_name]);

  const validate = () => {
    const newErrors = {};

    if (!formData.ingredient_name.trim()) {
      newErrors.ingredient_name = 'Ingredient name is required';
    }

    if (!formData.quantity || parseFloat(formData.quantity) <= 0) {
      newErrors.quantity = 'Quantity must be positive';
    }

    if (!formData.unit) {
      newErrors.unit = 'Unit is required';
    }

    setErrors(newErrors);
    return Object.keys(newErrors).length === 0;
  };

  const handleSubmit = async (e) => {
    e.preventDefault();

    if (!validate()) return;

    setLoading(true);
    try {
      const response = await api.post('/api/pantry', {
        ingredient_name: formData.ingredient_name.trim(),
        quantity: parseFloat(formData.quantity),
        unit: formData.unit
      });

      toast.success('Item added successfully!', {
        position: 'top-right',
        autoClose: 3000,
        hideProgressBar: false,
        closeOnClick: true,
        pauseOnHover: true,
        draggable: true
      });

      onSuccess(response.data);
      onClose();
    } catch (error) {
      console.error('Failed to add item:', error);

      if (error.response?.status === 400 && error.response.data.fields) {
        setErrors(error.response.data.fields);
        toast.error('Please fix the errors');
      } else {
        const message = error.response?.data?.message || 'Failed to add item';
        toast.error(message);
      }
    } finally {
      setLoading(false);
    }
  };

  const selectSuggestion = (suggestion) => {
    setFormData({
      ...formData,
      ingredient_name: suggestion.name,
      unit: suggestion.default_unit
    });
    setShowSuggestions(false);
  };

  if (!isOpen) return null;

  return (
    <>
      <div className="modal-backdrop" onClick={onClose} />
      <div className="modal" style={{ width: '500px' }}>
        <div className="modal-header">
          <h3 className="modal-title">Add Pantry Item</h3>
          <button 
            className="modal-close" 
            onClick={onClose}
            aria-label="Close"
          >
            ✕
          </button>
        </div>

        <form onSubmit={handleSubmit}>
          <div className="modal-body">
            <div className="form-group">
              <label htmlFor="ingredient_name" className="form-label form-label-required">
                Ingredient Name
              </label>
              <div style={{ position: 'relative' }}>
                <input
                  id="ingredient_name"
                  type="text"
                  value={formData.ingredient_name}
                  onChange={(e) => setFormData({ ...formData, ingredient_name: e.target.value })}
                  onBlur={() => setTimeout(() => setShowSuggestions(false), 200)}
                  onFocus={() => suggestions.length > 0 && setShowSuggestions(true)}
                  className={errors.ingredient_name ? 'input error' : 'input'}
                  placeholder="e.g., Milk, Eggs, Tomatoes"
                  autoComplete="off"
                  disabled={loading}
                />
                {searchLoading && (
                  <div style={{ position: 'absolute', right: '12px', top: '12px' }}>
                    <div className="spinner spinner-sm" />
                  </div>
                )}
                {showSuggestions && suggestions.length > 0 && (
                  <div style={{
                    position: 'absolute',
                    top: '100%',
                    left: 0,
                    right: 0,
                    backgroundColor: 'var(--color-white)',
                    border: '1px solid var(--color-gray-300)',
                    borderRadius: 'var(--radius-md)',
```

```python
from fastapi import APIRouter, Depends, HTTPException, Query
from sqlmodel import Session, select
from typing import List, Optional
from datetime import datetime

from app.database import get_session
from app.models import PantryItem, Ingredient
from app.services.pantry_service import (
    normalize_ingredient_name, 
    normalize_unit,
    fuzzy_search_ingredients
)
from pydantic import BaseModel, Field, validator


router = APIRouter()


class PantryItemCreate(BaseModel):
    """Request model for creating pantry item"""
    ingredient_name: str = Field(..., min_length=1, max_length=200)
    quantity: float = Field(..., gt=0)
    unit: str = Field(..., min_length=1)

    @validator('ingredient_name')
    def validate_ingredient_name(cls, v):
        if not v.strip():
            raise ValueError('Ingredient name cannot be empty')
        return v.strip()

    @validator('unit')
    def validate_unit(cls, v):
        allowed_units = ['units', 'grams', 'kilograms', 'liters', 'milliliters']
        if v.lower() not in allowed_units:
            raise ValueError(f'Unit must be one of: {", ".join(allowed_units)}')
        return v.lower()


class PantryItemUpdate(BaseModel):
    """Request model for updating pantry item"""
    quantity: float = Field(..., gt=0)
    unit: str = Field(..., min_length=1)

    @validator('unit')
    def validate_unit(cls, v):
        allowed_units = ['units', 'grams', 'kilograms', 'liters', 'milliliters']
        if v.lower() not in allowed_units:
            raise ValueError(f'Unit must be one of: {", ".join(allowed_units)}')
        return v.lower()


class PantryItemResponse(BaseModel):
    """Response model for pantry item"""
    id: int
    ingredient_name: str
    quantity: float
    unit: str
    category: str
    updated_at: str


class PantryListResponse(BaseModel):
    """Response model for pantry list"""
    items: List[PantryItemResponse]
    total: int


@router.get("/pantry", response_model=PantryListResponse, status_code=200)
def get_pantry(
    session: Session = Depends(get_session),
    user_id: int = Query(default=1, ge=1)
):
    """
    Get all pantry items for user.

    Returns list of pantry items with ingredient details.
    """
    try:
        # Query with join to get ingredient details
        statement = (
            select(PantryItem, Ingredient)
            .join(Ingredient)
            .where(PantryItem.user_id == user_id)
            .order_by(Ingredient.name)
        )

        results = session.exec(statement).all()

        items = [
            PantryItemResponse(
                id=item.id,
                ingredient_name=ing.name,
                quantity=item.quantity,
                unit=item.unit,
                category=ing.category,
                updated_at=item.updated_at.isoformat()
            )
            for item, ing in results
        ]

        return PantryListResponse(
            items=items,
            total=len(items)
        )

    except Exception as e:
        # Log error (in production, use proper logging)
        print(f"Error fetching pantry: {e}")
        raise HTTPException(
            status_code=500,
            detail={
                "error": "DatabaseError",
                "message": "Failed to fetch pantry items",
                "details": str(e)
            }
        )


@router.post("/pantry", status_code=201)
def add_pantry_item(
    item: PantryItemCreate,
    session: Session = Depends(get_session),
    user_id: int = 1
):
    """
    Add item to pantry.

    Auto-creates ingredient if it doesn't exist.
    Merges quantities if item already exists in pantry.
    """
    try:
        # Normalize ingredient name
        norm_name = normalize_ingredient_name(item.ingredient_name)

        # Find or create ingredient
        ing = session.exec(
            select(Ingredient).where(Ingredient.normalized_name == norm_name)
        ).first()

        if not ing:
            ing = Ingredient(
                name=item.ingredient_name,
                normalized_name=norm_name,
                category="Other",
                default_unit=item.unit
            )
            session.add(ing)
            session.commit()
            session.refresh(ing)

        # Normalize unit
        normalized_unit = normalize_unit(item.unit)

        # Check if item already exists in pantry
        existing = session.exec(
            select(PantryItem).where(
                PantryItem.ingredient_id == ing.id,
                PantryItem.user_id == user_id
            )
        ).first()

        if existing:
            # Merge quantities
            previous_quantity = existing.quantity
            existing.quantity += item.quantity
            existing.unit = normalized_unit
            existing.updated_at = datetime.now()
            session.add(existing)
            session.commit()

            return {
                "message": "Quantity updated",
                "id": existing.id,
                "previous_quantity": previous_quantity,
                "new_quantity": existing.quantity
            }
        else:
            # Create new pantry item
            pantry_item = PantryItem(
                ingredient_id=ing.id,
                quantity=item.quantity,
                unit=normalized_unit,
                user_id=user_id
            )
            session.add(pantry_item)
            session.commit()
            session.refresh(pantry_item)

            return {
                "message": "Item added",
                "id": pantry_item.id,
                "ingredient": {
                    "id": ing.id,
                    "name": ing.name,
                    "normalized_name": ing.normalized_name,
                    "category": ing.category
                }
            }

    except ValueError as e:
        raise HTTPException(
            status_code=422,
            detail={
                "error": "ValidationError",
                "message": str(e)
            }
        )
    except Exception as e:
        print(f"Error adding pantry item: {e}")
        session.rollback()
        raise HTTPException(
            status_code=500,
            detail={
                "error": "ServerError",
                "message": "Failed to add item",
                "details": str(e)
            }
        )


@router.patch("/pantry/{item_id}", status_code=200)
def update_pantry_item(
    item_id: int,
    update: PantryItemUpdate,
    session: Session = Depends(get_session)
):
    """Update pantry item quantity and unit."""
    try:
        item = session.get(PantryItem, item_id)
        if not item:
            raise HTTPException(
                status_code=404,
                detail={
                    "error": "NotFound",
                    "message": f"Pantry item with id {item_id} not found"
                }
            )

        # Update fields
        item.quantity = update.quantity
        item.unit = normalize_unit(update.unit)
        item.updated_at = datetime.now()

        session.add(item)
        session.commit()

        return {
            "message": "Item updated",
            "id": item_id,
            "updated_fields": ["quantity", "unit"]
        }

    except HTTPException:
        raise
    except Exception as e:
        print(f"Error updating pantry item: {e}")
        session.rollback()
        raise HTTPException(
            status_code=500,
            detail={
                "error": "ServerError",
                "message": "Failed to update item",
                "details": str(e)
            }
        )


@router.delete("/pantry/{item_id}", status_code=200)
```
